# MiniLauncher

お気に入りだけを出すホームと、アプリ名だけを縦に並べたアプリ一覧（右端にアルファベットスライダー付き）を持つ、ミニマルなAndroidランチャー。

## APKの作り方（GitHub Actions）

1. このフォルダの中身をGitHubの新しいリポジトリ（mainブランチ）にpushする
2. リポジトリの **Actions** タブ → **Build APK** の実行が終わるのを待つ（pushで自動実行。手動なら Run workflow）
3. 実行結果ページ下部の **Artifacts** から `MiniLauncher-debug-apk` をダウンロードして展開
4. `app-debug.apk` をスマホに送ってインストール（「提供元不明のアプリ」の許可が必要）

## 使い方

- ホームボタンを押して「常にこのアプリ」を選ぶとホームになる
- **ホーム（お気に入り）**: 画面下寄せの縦リスト。タップで起動、長押しで「上へ移動 / お気に入りから外す / アプリ情報」
- **ウィジェット**: ホームの空いている場所を長押し →「ウィジェットを追加」で一覧から選ぶ（システムの許可画面や、ウィジェット側の設定画面が出ることがある）。ウィジェットは画面上部、お気に入りはその下に並ぶ。削除は長押し →「ウィジェットを削除」
- **ホームのスワイプ操作**（左端からの右スワイプは端末の「戻る」と競合するので、少し内側から）:
  - 上スワイプ = 検索画面（アプリ一覧を開いて検索欄にキーボードを出す）、右スワイプ = 指定アプリ、下スワイプ = 通知パネル
  - 右スワイプのアプリの割り当て: アプリ一覧でアプリ名を長押し →「右スワイプで開くアプリにする」（もう一度選ぶと解除）。未設定のときはメッセージが出る
  - ウィジェットの上から始めたスワイプは、ウィジェット側の操作として扱う
- **左スワイプ**でアプリ一覧へ。右スワイプ、戻るボタン、ホームボタンのいずれかでホームに戻る
- **アプリ一覧**: タップで起動、長押しで「お気に入りに追加（外す） / アプリ情報」（アンインストールはアプリ情報から）
- 上部の検索欄にアプリ名の一部を入れると絞り込み（大文字小文字は区別しない）。キーボードの実行ボタンで、候補があれば先頭のアプリを起動、なければWeb検索。検索語があるときは一覧の末尾に「Webで検索」の行が出る（http(s)で始まる入力はそのままURLとして開く）。戻るボタンで検索を消し、もう一度でホームへ戻る。検索中はアルファベットスライダーを隠す
- **設定**: アプリ一覧の右下の歯車（⚙）をタップ
  - 文字の大きさ: 小 / 標準 / 大 / 特大（お気に入り・アプリ一覧・検索欄にすぐ反映）
  - 右スワイプで開くアプリ: 一覧から選ぶ（「未設定」で解除。長押しメニューからも設定できる）
  - ブラウザ: Web検索に使うブラウザを選ぶ（初期値は端末の標準ブラウザ）
- 右端の A〜Z / # をなぞるとその頭文字へジャンプ（日本語など英字以外の名前は # にまとまる）

## Android Studioで開く場合

フォルダをそのままOpenすればビルド・実行できる。
